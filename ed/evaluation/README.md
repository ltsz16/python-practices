# Python Evaluation Pack

This folder contains a practical assessment for mixed-skill Python teams.

## Purpose
Use this to measure each developer's Python understanding and identify the best training focus for the next sprint.

## Included files
- `junior.md` — beginner-friendly assessment
- `mid.md` — intermediate assessment
- `senior.md` — advanced assessment
- `rubric.md` — scoring guide
- `answer_key.md` — sample solutions

## Recommended timing
- 10 minutes: quick quiz
- 20 minutes: coding challenge
- 15 minutes: debugging task
- 15 minutes: scenario discussion
- Total: 60 minutes

## Scoring approach
Score individual skill areas rather than using one single grade.

## Suggested domains
- fundamentals and syntax
- functions and scope
- collections and dictionaries
- loops and conditionals
- file I/O
- exceptions
- debugging
- OOP basics
- tooling and environment
