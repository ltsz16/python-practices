# Python Evaluation Rubric

Use this rubric to score each learner by topic and skill.

## Score legend
- 0 = No understanding
- 1 = Minimal / inconsistent
- 2 = Basic understanding
- 3 = Solid understanding
- 4 = Strong understanding

## Skill areas

### 1. Fundamentals and syntax
- variables
- types
- operators
- indexing/slicing
- basic expressions

### 2. Data structures
- lists
- dictionaries
- sets
- tuples
- comprehensions

### 3. Functions and scope
- parameters
- return values
- local vs global scope
- reusable logic

### 4. Control flow
- conditionals
- loops
- break/continue
- boolean logic

### 5. Exceptions
- try/except
- raising exceptions
- handling edge cases

### 6. File I/O
- reading files
- writing files
- path usage
- parsing text

### 7. OOP basics
- classes
- instance methods
- attributes
- constructors

### 8. Debugging and reasoning
- identifying root cause
- tracing logic
- fixing simple bugs

### 9. Tooling and environment
- venv
- pip
- requirements.txt
- package installation

## Recommended use
Record one score per skill area. This lets you target training by deficiency rather than a single pass/fail result.
