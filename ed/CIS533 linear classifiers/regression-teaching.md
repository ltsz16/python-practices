# Regression & Classification Foundations (Perceptron, Linear Regression, MLE)

## 1. Big Picture
This document connects:
- Perceptron (classification)
- Linear Regression (prediction)
- Maximum Likelihood Estimation (MLE)

Core idea:
> We assume a model of how data is generated, then optimize parameters to best fit observed data.

---

## 2. Perceptron

### Key Idea
Find a hyperplane that separates data into two classes.

### Rule
Prediction:
\[ y = 	ext{sign}(w^T x) \]

### Update Rule
```python
# perceptron update
if y * (w @ x) <= 0:
    w = w + y * x   # push weights toward correct classification
```

### Intuition
- Only updates when wrong
- Moves decision boundary to fix mistakes

---

## 3. Linear Regression

### Assumption
Data is generated by:
\[ y = w^T x + 	ext{Gaussian noise} \]

### Objective
Minimize Mean Squared Error (MSE):
\[ rac{1}{n} \sum (w^T x_i - y_i)^2 \]

### Python Example
```python
import numpy as np

# X: (n, d) matrix, y: (n,)
def mse_loss(X, y, w):
    y_pred = X @ w            # predictions using matrix multiplication
    return np.mean((y_pred - y) ** 2)  # average squared error
```

---

## 4. MLE (Maximum Likelihood Estimation)

### Idea
Choose parameters that maximize probability of observed data:
\[ \max_w P(y | X, w) \]

### Trick
- Take log → turns product into sum
- Drop constants

### Result (for Gaussian noise)
MLE becomes:
\[ 	ext{minimize } \sum (w^T x_i - y_i)^2 \]

✅ This gives us linear regression loss!

---

## 5. Closed-Form Solution (Linear Regression)

\[ w = (X^T X)^{-1} X^T y \]

### Python
```python
# Solve using normal equation
w = np.linalg.pinv(X) @ y  # using pseudo-inverse (safe version)
```

---

## 6. Logistic Regression (MLE for Classification)

### Upgrade from Perceptron
Instead of hard decision:
- Use probability

\[ P(y=1|x) = \sigma(w^T x) \]

### Sigmoid Function
```python
def sigmoid(z):
    return 1 / (1 + np.exp(-z))  # maps to (0,1)
```

### Loss (Cross-Entropy)
Derived via MLE:
\[ \log(1 + e^{-y w^T x}) \]

### Python Example
```python
import numpy as np

# Loss function
def loss(X, y, w):
    z = X @ w                    # linear scores
    return np.mean(np.log(1 + np.exp(-y * z)))

# Gradient
def gradient(X, y, w):
    z = X @ w
    probs = 1 / (1 + np.exp(y * z))  # sigmoid(-y*z)
    return -(X.T @ (y * probs)) / len(y)

# Training
w = np.zeros(X.shape[1])
lr = 0.1

for _ in range(1000):
    w = w - lr * gradient(X, y, w)
```

- **Linear Regression**: Minimize squared errors
- **MLE**: Turn assumptions into objectives
- **Logistic Regression**: Smooth probabilistic classification
